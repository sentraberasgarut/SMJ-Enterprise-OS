# 15 Decision Memory

Enterprise-wide decision log, migration accounting, and knowledge gap
tracking. This folder is what prevents the enterprise from losing context
across future refactors — read `Migration_Report.md` and
`Knowledge_Gap_Report.md` before making any structural change to this
repository.

## Contents

- `Migration_Report.md` — what moved where during this refactor, and why
- `Knowledge_Gap_Report.md` — everything genuinely unknown, prioritized
- `Dependency_Map.md` — folder-to-folder dependency graph
- `Decision_Log.md` — consolidated record of every major decision across the enterprise's history

## Cross-References

Every folder in this repository references back to this one for its
specific gaps and decisions — this is the connective tissue of the
enterprise knowledge base.
