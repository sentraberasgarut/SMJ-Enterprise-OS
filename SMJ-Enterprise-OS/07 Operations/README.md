# 07 Operations

## SBGA — Consultation Model & Operating Rhythm

**Consultation Process:** The Five Diagnostic Questions (see
`04 Products/README.md`) precede every recommendation.

**Daily/Weekly/Monthly Operating Rhythm (AI Operating Manual):**
- Daily: Morning Dashboard Review → Claude Daily Brief → Marketing Execution
  Block → WhatsApp Consultation Review → Knowledge Capture
- Weekly: Sprint Planning (Mon) → Content Approval (Wed) → KPI Review (Fri)
  → Retrospective + Knowledge Update + Campaign Recommendation (Sun)
- Monthly: Business Review → Campaign Performance → KPI Rollup → Knowledge
  Audit → AI Ecosystem Review (first Monday)

16 recurring Google Calendar event series implement this rhythm — see
`13 Technology/README.md` for the Calendar/Drive/Notion split of
responsibility.

**Status:** ⚠️ This rhythm has been designed and scheduled but has never
been run for real (zero live campaigns to date). Its actual value is
unproven — flagged honestly rather than assumed.
