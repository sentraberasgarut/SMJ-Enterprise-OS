## What This Unit Has (and Doesn't Have)

**Has:** Real, validated transaction data going back to a mid-2026 operating
window; a working POS system (Loka Kasir); an established physical location
and customer base (even if mostly anonymous).

**Does not have:** Any of the marketing/content/CRM/campaign infrastructure
built for SBGA. No documented brand voice, no customer segmentation beyond
what's implicit in the POS data, no consultation-based sales model (it's a
straightforward retail counter, not a diagnostic-advisor sales model like
SBGA).

## Products Sold (from real POS data)

The catalogue spans grocery staples — rice varieties (7, shared with SBGA's
rice knowledge — see `04 Products/`), eggs ("Telur," the top seller by
volume), cooking ingredients ("Bahan Dapur" category), and bottled water,
among 44 total SKUs across 7 categories.
